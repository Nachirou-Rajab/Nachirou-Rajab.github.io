# Portfolio technique — Nachirou Mohamed Rajab

Portfolio des projets réseau et sécurité réalisés dans le cadre de la Licence Professionnelle
ASUR (INPTIC, Libreville).

**Site en ligne :** https://nachirou-rajab.github.io

## Structure

- `index.md` — page d'accueil et sommaire des projets
- `projets/` — les études de cas détaillées
- `assets/images/` — topologies et captures d'écran

## Règle de publication

Aucune donnée réelle n'est publiée : les adresses IP proviennent de plages privées (RFC 1918),
les mots de passe et clés sont retirés des extraits de configuration, et aucun projet couvert
par un accord de confidentialité n'y figure.
